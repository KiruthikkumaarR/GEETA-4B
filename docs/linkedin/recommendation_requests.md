# LinkedIn recommendation requests

**Goal:** 2–3 recommendations. One from a manager, one from an academic, and one from a teammate if possible.
**How to send:** open their profile → **More** → **Request a recommendation** → pick relationship and position → paste the message → Send.

A specific request gets you a specific recommendation. Each message tells them **what to mention**, which makes it easier for them to say yes and get it done quickly.

## Tips
- **Offer to write one back.** Most people say yes faster when it goes both ways.
- **Follow up once** after about a week if you haven't heard back. People forget; they're rarely saying no.
- When it arrives, you approve it before it appears on your profile, so nothing goes public without your OK.
